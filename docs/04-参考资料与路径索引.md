## 2. 本机关键路径（Cursor 3.24.18）

### 安装目录
```
%LOCALAPPDATA%\Programs\cursor\
├── Cursor.exe
└── resources\app\
    ├── product.json                                  ← 版本信息 + checksums（6 个文件）
    ├── out\
    │   ├── nls.keys.json                              ← 权威键表（1150 模块 / 13530 键）
    │   ├── nls.messages.json                          ← 英文原文（13530 条，逐位对应）
    │   ├── main.js                                    ← Electron 主进程
    │   └── vs\
    │       ├── code\electron-sandbox\workbench\
    │       │   ├── workbench.html                     ← 校验文件 / 注入点
    │       │   └── workbench.js                       ← setupNLS() 所在
    │       └── workbench\
    │           ├── workbench.desktop.main.js          ← 39.8 MB，校验文件（主界面）
    │           ├── workbench.desktop.main.css         ← 校验文件
    │           ├── workbench.glass.main.js            ← 47.4 MB，免校验（智能体窗口）
    │           └── workbench.anysphere-ui-automations.js ← 免校验
    └── extensions\                                    ← 内置扩展（116 个）
```

### 用户目录
```
%USERPROFILE%\.cursor\
├── argv.json                       ← "locale": "zh-cn" 显示语言开关
└── extensions\                     ← 用户扩展（语言包装在这里）
```

```
%APPDATA%\Cursor\
└── User\globalStorage\state.vscdb  ← SQLite，含界面文案缓存（汉化不生效时需清理）
```

## 5. 术语对照（翻译时统一使用）

> 权威来源是 [`data/terms.json`](../data/terms.json)，本节为其摘要。
> 翻译前以 JSON 为准，本节仅供速览。

### 5.1 保留原文（keepAsIs）

| 英文 | 说明 |
| --- | --- |
| Cursor | 产品名 |
| Composer | Cursor 专有功能名。**不可译作「编辑器」**——会与 VS Code 原生 Editor 的通用译名冲突 |
| Glass | 智能体窗口代号 |
| Bugbot / Notepad | Cursor 专有功能名（Notepad 译「记事本」会与 Windows 记事本混淆） |
| Cursor Tab / Cursor Blame | 品牌功能名 |
| MCP / Token / Commit / Pull Request / Git / GitHub | 技术专名 |
| Worktree | git worktree，且实测全为开发者向字符串 |

### 5.2 需翻译（terms）

| 英文 | 中文 | 说明 |
| --- | --- | --- |
| Agent | 智能体 | 不译为"代理" |
| Subagents | 子智能体 | |
| Cloud Agents | 云端智能体 | |
| Rules / Skills / Hooks | 规则 / 技能 / 钩子 | |
| Plugins | 插件 | 对应 VS Code 的 Extension，但 Cursor 语境用「插件」 |
| Tools & MCP | 工具与 MCP | |
| Indexing & Docs | 索引与文档 | |
| Code Intelligence | 代码智能 | |
| Plan Mode | 计划模式 | |
| Blame | 溯源 | **仅通用 git blame**；Cursor Blame 保留原文 |
| Tab | 选项卡 | **仅标签页语义**；Cursor Tab 补全功能保留原文 |
| Extension / Workspace / Terminal / Settings | 扩展 / 工作区 / 终端 / 设置 | 与官方语言包保持一致 |
| Diff / Review / Snapshot / Checkpoint | 差异 / 审查 / 快照 / 检查点 | |

> **两处必须分治的歧义词**：`Tab`（标签页 vs Cursor Tab）与 `Blame`（通用 vs Cursor Blame）。
> 一刀切会在两个方向上同时出错——这是初版术语表最容易被误用的地方。
