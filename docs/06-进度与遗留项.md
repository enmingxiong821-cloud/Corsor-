## §3 待办与遗留项

### 3.1 本地可解，但需先设计闸门

**① `CURSOR_DASHBOARD_COPY` 的带空格键** —— `Additional usage credits` /
`Monthly additional usage` / `Set auto top-up`
- **阻塞原因**：这是**键含空格**的映射表。`NAV_MAP_RE` 的键字符类是小写 id、
  `CAMEL_MAP_RE` 要求驼峰键，现有十条规则一条都匹配不上。
- **下手点**：单开规则 ⑪（新增 `SPACED_MAP_RE`，或在现有键字符类里放开空格）。
  `CLAUDE.md` 明令：**放宽前先按增量重测**。

### 3.2 本地无解（由服务端下发）

**③ 语音模式的那句提示**、**④ `Premium` / `Get more usage with Premium` / `Upgrade to Premium`**
- **阻塞原因**：三个 bundle 里各出现 **0 次**，由服务端下发，语言包也够不着。
- **下手点**：本地无解，只能等 Cursor 自己接入语言包。**不要为凑数字硬造译文。**

### 3.3 已明确不做

**跨平台（macOS / Linux）** —— 2026-10-16 经询问后由用户明确推迟。三个已知阻塞点：
`src/m4/fontfix.mjs` 的 `FONT_STACK` 写死 Windows 字体；入口全是 `install.cmd` / `uninstall.cmd`
与 Windows 计划任务；`src/deploy/process.mjs` 在非 win32 直接返回 `null`，少了「Cursor 在运行
就拒绝写入」这道检查。**不要主动提议做跨平台**，用户要在 Mac 上用再按上面清单做。

**第四个目标 `workbench.xai-commerce-prepaid.js`** —— 免校验，但实测命中 0 条，无需处理。

### 3.4 换 Cursor 版本必重验

同一大版本的补丁版（3.25.x）bundle 主要变 hash，规则基本可沿用。**跨大版本**时
`sync` 虽会自动重跑，但有三条必须重新实证，不能想当然：

- **不能跨版本复用备份**（项目铁律）
- 覆盖率基准要重算 —— 基准取**备份里的原始英文表**，不是磁盘上当前文件
  （装过之后后者已是中文，当「英文原文」用会凭空报缺口）
- 两条判定会失效，须重跑：① 标识值守卫挡下的那批值；② 计费名单里**刻意保留英文的那三条串**
  （`Share exceeds content limits` / `No response was received within the time limit` /
  `The AI provider is rate-limiting…`），它们是按当前 bundle 逐条核过使用站点得出的结论
